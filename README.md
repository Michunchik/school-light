# school-light

Учебная консольная версия школьной логики: расписание занятий,
домашние задания, ставки и зарплата преподавателей. Данные только в памяти, без базы и фреймворков.
Правила (ставки: своя → школы → по умолчанию, пробное занятие, периоды выплат) взяты из рабочей платформы школы.

Это семинарский проект по теме «Вынос вычислений и улучшение структуры действий».
История коммитов показывает три этапа:

1. исходное состояние: обычный ООП-код, методы меняют поля и печатают в консоль;
2. вынос вычислений из действий: чистые функции с аргументами и возвращаемыми значениями;
3. улучшение действий: copy-on-write, неизменяемые данные, конструкторы.

## Запуск

Нужен Node.js 22.18 или новее (запускает TypeScript без сборки).

```bash
npm start      # демо-сценарий
npm test       # тесты
```

## Предметная область

- **Teacher**: преподаватель, свои ставки, занятия
- **Student**: ученик, его занятия и домашние задания
- **Group**: группа учеников, групповые занятия
- **Lesson**: занятие (время, формат, статус, ДЗ, выплата)
- **School**: хранит всех, общие ставки, «сегодня»

Операции: назначить, перенести и отменить занятие, провести занятие, выдать и выполнить ДЗ,
найти свободные окна, найти конфликты, посчитать зарплату за период, отметить выплату,
отчёт по ученику, отчёт по группе, сводка по школе.
